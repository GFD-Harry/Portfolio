# Portfolio Description
## 1. Mục tiêu
Xây dựng một website portfolio cá nhân giúp nhà tuyển dụng nhanh chóng hiểu tôi là ai, có định hướng nghề nghiệp gì, sở hữu kỹ năng nào và đã thực hiện những dự án nào

## 2. Scope
- Giao diện sáng, hiện đại, tối giản
- Nội dung tiếng việt/anh
- Triển khai vercel
- Intro: tên, vị trí, Software Engineer, mô tả ngắn
- About Me: học vấn, định hướng, sở thích AI
- Projects: 3 dự án
- Skills and Tools: ngôn ngữ, frontend, backend, AI, công cụ
- Education: SIU
- Gồm: Contact (email, github, linkedln), sidebar (điều hướng giữa các phần), resume (nút tải CV về)

## 3. Out of scope
- Tối ưu cho điện thoại
- Backend, DB, trang quản trị
- Hiệu ứng phức tạp

## 4. Kiến trúc
- Frontend: React + Typescript
- Build: Vite
- Styling: Tailwind CSS
- Lint: ES Lint
- SOng ngữ: React Context + dữ liệu typescript
- Source control: github
- Hosting: vercel
